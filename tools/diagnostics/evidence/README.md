# 脱敏运行工件归档

本目录保存真实产品路径产生的工件的脱敏副本，不是合成测试夹具。
`archive.json` 记录来源运行目录、原文件及脱敏副本各自的 SHA-256；Git 不转换副本换行符。
绝对路径改为可移植占位符，设备序列号和配置字符串中的端点改为 `<device>`；
调用链、结果、步骤、合同字段和时间戳保持原值。本机原件保留在忽略目录，不入库。
`audit_real_records.py` 将合同裁决与 `index.json`、`session-log.jsonl` 交叉核对，
校验和不匹配、工件缺失或结论不一致都会令验收失败。
